# Crédits des visuels d'exercice

- **Photos animées (la majorité)** : [free-exercise-db](https://github.com/yuhonas/free-exercise-db)
  (domaine public, Unlicense), deux positions assemblées en WebP animé.
  Variantes proches de l'exercice du programme : `oiseau_halteres` (version assise),
  `dev_militaire_assis` (version haltères).
- **ski_erg.webp** : « CrossFit workout on SkiErg », Kiet Le, [CC BY 2.0](https://creativecommons.org/licenses/by/2.0/),
  via [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:CrossFit_workout_on_SkiErg_DSC1807.jpg). Redimensionnée.

- **toes_to_bar, extension_thoracique, hanche_90_90, grenouille** : animations
  [FitnessProgramer.com](https://fitnessprogramer.com) (non libres, usage personnel uniquement).
  `grenouille` montre la « Frog Pose ».

- **Animations dessinées pour Grizzlift** (mannequin schématique) : stir_the_pot, rotation_bassin_swissball,
  open_book, rotation_externe_epaule, dragon_flag, pike_swiss_ball, tuck_lsit, couch_stretch,
  dorsiflexion_cheville, ischio, quad_debout.
