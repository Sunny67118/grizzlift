# Crédits des visuels d'exercice

- **Toutes les animations sauf deux** : photos de [free-exercise-db](https://github.com/yuhonas/free-exercise-db)
  (domaine public, Unlicense), deux positions assemblées en WebP animé.
  Certaines sont des variantes proches de l'exercice du programme :
  `couch_stretch` (Kneeling Hip Flexor), `ischio` (Standing Hamstring and Calf Stretch),
  `quad_debout` (Standing Elevated Quad Stretch), `dorsiflexion_cheville` (Calf Stretch Hands Against Wall),
  `pike_swiss_ball` (Exercise Ball Pull-In, version genoux fléchis), `oiseau_halteres` (version assise),
  `dev_militaire_assis` (version haltères).
- **ski_erg.webp** : « CrossFit workout on SkiErg », Kiet Le, [CC BY 2.0](https://creativecommons.org/licenses/by/2.0/),
  via [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:CrossFit_workout_on_SkiErg_DSC1807.jpg). Redimensionnée.
- **tuck_lsit.webp** : « Figura L-Sit na paraletkach », BandiSW, [CC BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/),
  via [Wikimedia Commons](https://commons.wikimedia.org/wiki/File:Figura_L-Sit_na_paraletkach.jpg). Redimensionnée.

- **toes_to_bar, dragon_flag, extension_thoracique, hanche_90_90, grenouille** : animations
  [FitnessProgramer.com](https://fitnessprogramer.com) (non libres, usage personnel uniquement).
  `dragon_flag` montre la variante « Dragon Flag Leg Raise » (sur banc), `grenouille` la « Frog Pose ».

- **stir_the_pot, rotation_bassin_swissball, open_book, rotation_externe_epaule** : animations dessinées
  pour Grizzlift (script de génération, mannequin schématique).
